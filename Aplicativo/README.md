# BenaHdp - Aplicativo

Esta pasta contem a versao empacotada do BenaHdp para Windows.

## Como usar

1. Execute `BenaHdp.exe`.
2. Carregue a imagem base e a imagem sobreposta em formato PNG.
3. Ajuste posicao, rotacao, zoom, transparencia e cores conforme necessario.
4. Use as ferramentas de minucias e matching quando precisar comparar pontos.
5. Salve o trabalho em um arquivo `.zip` para reabrir depois.

## Arquivos

- `BenaHdp.exe`: aplicativo Windows.
- `README.md`: este manual resumido.
- `Leia-me.txt`: instrucoes rapidas.

Se o executavel nao estiver disponivel, execute pelo codigo fonte:

```powershell
cd "..\Código Fonte"
python -m pip install -r requirements.txt
python Benahdp.py
```
